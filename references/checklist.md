# 快速扫描清单

用户不要完整报告、只要快速 yes/no 时用。每个清单末附时效核对提醒：法律 / 平台规则至少 6 个月核一次，云厂商 / API 定价至少季度核一次。

## 红线 — 即时砍

任一答"是"即停。

- [ ] 点子是否涉及转售或伪装别人的产品 / API？
- [ ] 是否聚合盗版或未授权内容？
- [ ] 是否帮用户在平台作弊（评论、互动、排名）？
- [ ] 是否以擦边或边缘性内容作为主要流量来源？
- [ ] 是否生成 deepfake / 换脸 / 换声 / 不设强限制？
- [ ] 是否可能给真实用户发出受监管的建议（医疗 / 法律 / 金融 / 投资）？
- [ ] 是否把 AI 放进高风险决策（诊断、治疗、合同审查、交易）？
- [ ] 是否需要用户难以取得的资质 / 许可？

**先核**：当前 API 厂商 ToS、网信办最新规章、对应行业主管部门近期处罚案例。

## 价值 — 快速测试

三问。两个"否"或一个强"否" → 拒。

- [ ] 能否说出 5 个目标用户会答"是的，我正为这事挣扎"？
- [ ] 自己试用过 top 3 现有方案，并找到具体挫败点？
- [ ] 受众是否大到 ~5% 转化 / 采纳能覆盖持续成本 + 你的时间？

**先核**：对应社群的近期讨论、应用商店差评、行业报告最新用户量。

## 难度 — 在预算内？

只问核心组件。

- [ ] 今天能从零写出来吗？
- [ ] 不能 → 在项目时间窗内能学会吗？
- [ ] 不能 → 有可靠的库 / 服务 / 合作方吗？

三个都答否 → 难度超预算。

**先核**：官方文档完整度、社区学习资源量、GitHub 同类项目活跃度。

## 成本 — 7 类全覆盖

别跳过哪怕"明显为零"的类别。

- [ ] 服务器 / 基础设施（持续）
- [ ] 第三方 API 订阅（按量计费）
- [ ] 一次性（域名 / 证书 / 设计）
- [ ] 维护（持续）
- [ ] 分发 / 营销（通常 > 技术成本）
- [ ] 冷启动跑道（几周零回报）
- [ ] 运营（客服 / 社群 / 反馈）

**先核**：各云厂商与 API 服务商当前定价页，最近一次报价日期记下来。

## 边界 — 预设

动手前写下，不要事后补。

- [ ] v1 包括：___
- [ ] v1 不包括：___
- [ ] 功能蔓延守卫：用户要 X 时我会说 ___

## 未知成本 — 依赖审计

每个外部依赖检查：

- [ ] 提供方能单方面调价吗？
- [ ] 提供方能停服吗？
- [ ] 平台规则变化能让这事失效吗？
- [ ] 上述任一明天发生，项目会怎样？

答"项目死了"→ 重做依赖设计再写。

**先核**：依赖服务状态页（status page）、过往事故记录、近期定价变更公告。

## 时效核对提醒

每条结论后必须能答出来：

- 来源：___（链接 / 文档名 / 页码）
- 核实日期：___（YYYY-MM-DD）
- 该源合理有效期：___（法规 6 个月 / 定价 3 个月 / 模型能力 6 个月 / 行业报告 12 个月）

下次复核日期 = 核实日期 + 合理有效期。
